Installer SoundLive NDI

Installe d’abord le logiciel sur le poste, puis raccorde le lecteur à ta régie lorsque tu es prêt.

Raspberry Pi OS 64 bits

Lecteur. Télécharge et décompresse le kit, puis ouvre un terminal dans le dossier et lance :

bash setup-linux.sh

Télécharger — Raspberry Pi

Ubuntu Desktop 64 bits

Régie ou lecteur. Télécharge et décompresse le kit, puis lance sous ton compte de bureau, sans sudo :

bash setup-linux.sh

Télécharger — Ubuntu

Windows 10 / 11 x64

Régie ou lecteur. Décompresse le kit et lance setup-windows.cmd. Pour un lecteur, utilise le compte administrateur du poste.

Télécharger — Windows

Les trois liens téléchargent le même kit officiel multiplateforme. La signature de publication est disponible sur la page de la version.

1. Installer

  1. Choisis Régie ou Lecteur dans le menu de l’installateur.
  2. Pour un lecteur, conserve la connexion actuelle pendant l’installation. Les paramètres réseau définitifs seront saisis uniquement dans Ajouter un écran. Pour la régie, utilise Gestion réseau après installation.
  3. Accepte les demandes d’administration et termine la configuration de la session.
  4. Pour une régie, lance SoundLive-NDI Régie. Pour un lecteur, aucun code n’est nécessaire pendant l’installation.

Une connexion Internet peut être nécessaire. Le lecteur Windows nécessite Python x64 avec Tcl/Tk, le runtime NDI 6, SDL2.dll x64 et lecteur-ndi-windows.exe. Si le binaire n’est pas dans le kit, utilise la procédure de compilation du README officiel. La régie sur Raspberry Pi n’est pas validée.

2. Configurer le réseau et raccorder un lecteur

  1. Dans la régie, clique sur Ajouter un écran, sélectionne son type et son nom.
  2. Choisis Associer uniquement pour conserver le réseau actuel ou Préparer une IPv4 fixe et associer pour configurer le hostname, les interfaces Ethernet et Wi-Fi, le SSID, la passerelle et les DNS.
  3. Copie la ligne de commande complète générée par le formulaire.
  4. Sur le lecteur, ouvre le terminal dans le dossier du kit décompressé (PowerShell administrateur sous Windows, terminal du compte du bureau sans sudo sous Linux). Colle et exécute la commande. La clé Wi-Fi peut être saisie dans le formulaire (elle figure alors dans la commande, à garder confidentielle) ou demandée localement sur le lecteur.
  5. Redémarre le lecteur et vérifie son état dans la régie.

Le code expire après 15 minutes. Les paramètres réseau sont saisis une seule fois, dans la régie. La commande existante peut aussi installer directement un lecteur non encore préparé. Le raccourci de raccordement simple reste disponible pour les lecteurs dont le réseau est déjà configuré.

3. Désinstaller SoundLive NDI

Arrête la régie ou le lecteur, puis relance l’installateur depuis un kit décompressé séparé. Choisis Désinstaller la régie ou Désinstaller le lecteur.

  • Programme seulement : conserve les données.
  • Programme et données : supprime aussi les associations ou la configuration locale.
  • Nettoyage système dédié : retire également les composants SoundLive identifiés. Exécute localement sur un poste dédié, avec les droits d’administration nécessaires.
  • Simulation : affiche les suppressions prévues sans rien modifier.

Sauvegarde les données avant purge. Les dépendances partagées sont conservées. Vérifie manuellement les réglages réseau, SSH, VNC/RDP, veille et connexion automatique dont l’état précédent n’est pas connu.
