      Déployer un lecteur via SSH
      
    
      Prépare d’abord la clé SSH sur le nouveau lecteur avec la page HTTPS
      /addsshkey (port 8766). Le déploiement vérifie l’empreinte SSH hôte.
      
    
      
      
      
      
      
      
    
      
    
      Sur le lecteur Ubuntu/Pi, relève l’empreinte via
      ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub.
      Windows : consulte C:\ProgramData\ssh.
      
    
      Git et Internet sont requis. Sur Linux, le mot de passe sudo peut
      être fourni pour cette seule installation ; il transite via HTTPS puis SSH,
      n’est pas enregistré et ne sera pas affiché dans le journal.
      Windows requiert un compte SSH administrateur et les composants NDI.
